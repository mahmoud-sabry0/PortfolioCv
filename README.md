# Mahmoud Sabry | Portfolio

Personal portfolio of Mahmoud Sabry, Front-End Developer (React.js) from Cairo, Egypt.

**Live site:** https://mahmoud-sabry0.github.io/PortfolioCv/

![Portfolio preview](public/og-image.jpg)

## Features

- Single-page React app with smooth in-page navigation and a scroll-aware nav bar
- Projects, skills and services rendered from one data file (`src/data.js`)
- Working contact form powered by EmailJS
- Responsive layout for mobile, tablet and desktop
- Accessible: labelled icon links and form fields, visible keyboard focus, reduced-motion support
- SEO and link-preview (Open Graph) tags

## Tech

React 19 · Vite 7 · CSS3 · react-icons · EmailJS · GitHub Pages

## Run locally

```bash
npm install
npm run dev       # start the dev server
npm run build     # production build to dist/
npm run deploy    # build and publish to GitHub Pages
```

## Updating content

Edit `src/data.js` to change projects, skills, services, contact links and About details. Project screenshots are in `src/assets/projects/`. To update the downloadable CV, replace `src/assets/Mahmoud_Sabry_CV.pdf`.
